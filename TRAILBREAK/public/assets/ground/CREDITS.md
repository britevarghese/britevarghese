# Ground textures

Photo-scanned ground materials, all CC0 (public domain), packed for the game by `tools/ground.py` (colour resized to
1024 px, normal and height to 512 px, WebP). Thanks to their authors:

| Layer | Source |
|---|---|
| grass | [Grass 004](https://ambientcg.com/view?id=Grass004), ambientCG |
| forest floor | [Ground 076](https://ambientcg.com/view?id=Ground076), ambientCG |
| dirt trail | [Rocky Trail](https://polyhaven.com/a/rocky_trail) by Amal Kumar, Poly Haven |
| gravel | [Rock Ground](https://polyhaven.com/a/rock_ground) by Rob Tuytel, Poly Haven |
| rock | [Rock 028](https://ambientcg.com/view?id=Rock028), ambientCG |
| mud | [Brown Mud 03](https://polyhaven.com/a/brown_mud_03) by Rob Tuytel, Poly Haven |
| sand | [Coast Sand 01](https://polyhaven.com/a/coast_sand_01) by Rob Tuytel, Poly Haven |
| snow | [Snow 02](https://polyhaven.com/a/snow_02) by Rob Tuytel, Poly Haven |
| river stones | [Ganges River Pebbles](https://polyhaven.com/a/ganges_river_pebbles) by Amal Kumar, Poly Haven |

The boulders wear the rock layer.
